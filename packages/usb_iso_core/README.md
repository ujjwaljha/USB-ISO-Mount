# usb_iso_core

Shared Dart library for USB ISO Mount: list removable disks, classify Windows / WinPE / Linux ISOs, write a bootable USB (FAT32 file-copy, Windows FAT32+NTFS, raw hybrid image, or a GRUB multiboot stick), and format a spare USB as FAT32, exFAT, or NTFS.

See the [repository README](../../README.md).
